# Coders of Delhi

A pure-Python data analysis project exploring friend suggestions, page recommendations, and data cleaning without using any external libraries like NumPy or Pandas.

## 📌 Project Overview
This project performs manual data processing using only core Python. It demonstrates:
- Reading and parsing raw JSON data
- Cleaning and organizing dataset fields
- Creating simple recommendation logic
- Extracting insights using lists, dictionaries, loops, and conditions

The goal was to perform data analysis **without relying on third‑party libraries**, focusing instead on logic building and understanding how raw data transforms into meaningful insights.
